MY LEARNING OS — ONLINE

1. Buka Supabase SQL Editor.
2. Jalankan semua isi supabase-schema.sql.
3. Pastikan Email Auth aktif di Authentication > Providers.
4. Upload folder ini ke GitHub Pages, Vercel, Netlify, atau hosting HTTPS.
5. Buka website, pilih Daftar, konfirmasi email jika diminta, lalu Login.

Supabase URL dan publishable key sudah dikonfigurasi di index.html.
Jangan pernah memasukkan service_role/secret key ke frontend.

Progress disimpan per user dengan Row Level Security.

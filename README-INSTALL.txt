INSTALL:
1. Upload/replace ONLY these four files in GitHub:
   js/config.js
   js/auth.js
   js/progress.js
   js/app.js
2. In js/config.js replace PASTE_YOUR_SUPABASE_ANON_KEY_HERE with Supabase anon/public key.
3. Do NOT use service_role.
4. Keep data/curriculum.js, index.html, style.css, and Supabase table.
5. Wait for GitHub Pages deployment, then Ctrl+F5.

This version stores checklist by Supabase user_id and does not use localStorage as the source of truth.

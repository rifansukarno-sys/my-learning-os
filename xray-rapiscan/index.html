Alur kerja mesin

Pahami “cerita” satu bagasi dari listrik sampai menjadi gambar.

1. PowerAC masuk → breaker → proteksi → transformer → distribusi.
2. Generate X-rayTube + filament + HV membentuk sinar-X.
3. Objek lewatConveyor membawa bagasi melalui tunnel.
4. DetectDAB menangkap sinyal → ADC mengubah analog menjadi digital.
5. ImageCI + computer + software memproses data menjadi gambar.
Mindset teknisi

Jangan langsung ganti part.

Mulai dari gejala, periksa safety dan power, telusuri jalur kontrol, lalu isolasi sumber fault. Satu error dapat berasal dari kabel, power supply, sensor, board, inverter, atau komponen mekanik.
